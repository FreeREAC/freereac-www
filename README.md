# freereac-www

The FreeREAC project website: what FreeREAC is, what each repository does, how to
install it, how to get a Roland REAC stagebox running on Linux, the licence, and where
the sources are. It is in English, with a Catalan version at `/ca`.

FreeREAC is an independent interoperability project, not affiliated with, sponsored by,
or endorsed by Roland. REAC is a trademark of Roland Corporation; see [NOTICE](NOTICE).

## Install

There is nothing to install: the site is a set of static pages, published by GitHub
Pages from `main` (see `.github/workflows/pages.yml`). To build it, preview it, or serve
your own copy, see [BUILDING.md](BUILDING.md).
